This repository contains the following add-ons:

### [Viseron](./viseron)

![Supports amd64 Architecture][amd64-shield]
![Supports aarch64 Architecture][aarch64-shield]
![Supports armv7 Architecture][armv7-shield]

Self-hosted, local only NVR and AI Computer Vision software with features such as object detection, motion detection, face recognition and more.

## Installation

1. Navigate to the Home Assistant Add-on Store
2. Click the menu icon (⋮) in the top right corner
3. Select "Repositories"
4. Add this repository URL: `https://github.com/roflcoopter/viseron-hass-app`
5. Find "Viseron" in the add-on list and click on it
6. Click "Install"
